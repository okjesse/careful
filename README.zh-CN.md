# careful

一个 Claude Code skill，用于代价高的工作：方案设计、技术选型、调研分析、商业判断，以及要上线、花钱、对外或不可逆的代码改动。

[English](README.md)

## 它做什么

防四种常见错误，每种对应一条原则：

| 错误 | 原则 |
| --- | --- |
| 解错了问题，或者把没核实的前提当事实 | 2. 第一性原理 |
| 重复造轮子，或者跟风 | 3. 最佳实践 |
| 分类重叠或遗漏，结论无法追溯 | 4. MECE |
| 没人试过把它推翻 | 5. 对抗式审查 |

六个步骤，每步必须产出一个用户看得见的东西，没有产出就等于没做：

1. **定义问题**：一句话说清为谁、解决什么、成功标准是什么、约束是什么。
2. **第一性原理**：剥掉现在的形式，说清这东西本质上是什么；把已知信息分成事实 / 假设 / 惯例；把目标写成公式；问理论极限在哪。
3. **最佳实践**：谁已经解决过。找四样东西：最好的结果、做出它们的方案、正在做的人的第一手记录、方法论。必须点名具体的，类别不算对标。技术类三选一：用现成 / 改现成 / 自研。
4. **MECE**：每层只按一个维度拆，第一层用主维度，即分支会导向不同行动的那个；做互斥检查和穷尽检查。
5. **对抗式审查**：事前验尸、最强反方、翻转条件三个固定动作，问题分致命 / 重要 / 次要，致命问题不解决不交付。
6. **交付**：只做回答问题所需的最少的事，能跑的检查就跑。结论 → 依据 → 对标 → 假设 → 最可能错在哪 → 下一步 → 来源。

深度按风险分级。几分钟能做完、可逆的小事直接跳过。花钱、上线、对外、不可逆的大事，对抗审查交给独立子代理。

## 安装

作为 plugin 安装（推荐，之后用 `/plugin marketplace update` 拿更新）：

```
/plugin marketplace add okjesse/careful
/plugin install careful@careful
```

这种装法调用名是 `/careful:careful`。

用 git clone，全局所有项目可用：

```bash
git clone https://github.com/okjesse/careful ~/.claude/skills/careful
```

或只装到一个项目：

```bash
git clone https://github.com/okjesse/careful .claude/skills/careful
```

一台机器只用一种装法。clone 的副本和 plugin 同名会冲突，只有 plugin 那份会加载。

发新版本时改 `.claude-plugin/plugin.json` 里的 `version`，plugin 用户只在版本号变化时收到更新。

这种装法调用名是 `/careful`。两种装法下，涉及方案设计、选型、调研、上线或不可逆改动的任务，Claude 都会自动触发。

## 关于语言

SKILL.md 用英文写，因为读它的是 Claude 不是人。回复语言跟随对话语言，中文提问会得到中文回答。description 里保留了中文触发语（帮我想清楚、别人怎么做的、有什么坑、帮我把关），中文提问能稳定命中。

完整流程见 [SKILL.md](SKILL.md)。
